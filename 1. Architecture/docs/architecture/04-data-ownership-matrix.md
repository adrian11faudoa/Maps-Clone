# 04 — Data Ownership Matrix

Legend: **Canonical** = authoritative source of truth. **Derived** = projection/materialization that can be rebuilt from a canonical source. **Ephemeral** = intentionally short-lived, not a durable record of truth beyond its operational window.

| Entity | Kind | Canonical owner (domain) | Storage system | Primary key strategy | Consumers | Publication mechanism | Deletion behavior | Retention |
|---|---|---|---|---|---|---|---|---|
| `User` | Canonical | Identity | PostgreSQL (`identity` schema) | ULID | all domains (by reference `user_id`) | `UserRegistered` event | Soft-delete + scheduled hard-delete per privacy request (see `17-security-privacy-architecture.md`) | Account lifetime + legal hold window |
| `Credential` | Canonical | Identity | PostgreSQL (`identity` schema), hashed only | ULID | Identity only | none (never leaves domain) | Hard-delete on account deletion | Account lifetime |
| `Device` | Canonical | Identity | PostgreSQL (`identity` schema) | ULID | Identity, Navigation (device context) | `DeviceRegistered` (internal) | Hard-delete on user request or account deletion | Account lifetime |
| `Session` / `RefreshToken` | Canonical | Identity | PostgreSQL (`identity` schema) + Redis (active session cache) | ULID | API edge (validation) | `SessionCreated`, `SessionRevoked` | Hard-delete on logout/revocation/expiry | Session TTL (see `08-auth-architecture.md`) |
| `UserProfile` | Canonical | Users | PostgreSQL (`identity` schema) | = `User.id` | Places (attribution), Reviews (attribution), Contributions | `UserProfileUpdated` | Soft-delete with account | Account lifetime |
| `Place` | Canonical | Places | PostgreSQL/PostGIS (`places` schema) | ULID | Search (indexes), Routing (POI endpoints), Saved Places, Reviews, Contributions, Map-tile (POI layer) | `PlaceCreated`/`PlaceUpdated`/`PlaceDeleted`/`PlaceModerated` | Soft-delete (tombstone retained for dedupe/audit) | Indefinite (tombstoned) |
| `Address` | Canonical | Places | PostgreSQL/PostGIS (`places` schema) | ULID | Geocoding, Places | `PlaceUpdated` (embedded) | Cascades with owning `Place` | Indefinite (tombstoned) |
| `Category` | Canonical | Places | PostgreSQL (`places` schema) | slug (stable string ID) | Search, Places, clients (static reference data) | `CategoryTaxonomyUpdated` (internal, low-frequency) | Soft-delete (deprecate, do not remove) | Indefinite |
| `PlaceOwnership` | Canonical | Places | PostgreSQL (`places` schema) | ULID | Places, Contributions (elevated edit rights) | `PlaceOwnershipGranted`/`Revoked` | Hard-delete on revocation | Until revoked |
| `GeographicFeature` / `RoadSegment` / `AdministrativeRegion` | Canonical | Geographic/Address Data | PostgreSQL/PostGIS (`geodata` schema) | ULID + external source ID preserved | Geocoding, Routing (graph build), Map-tile, Search (region bias) | `MapDataVersionPublished` | Versioned replace (new `MapDataVersion`), old versions retained for rollback window | Current + N previous versions (see `09-...md`) |
| `MapDataVersion` | Canonical | Geographic/Address Data | PostgreSQL (`geodata` schema) + object storage (raw/normalized snapshots) | ULID, monotonic version number | Routing, Map-tile, Search, Analytics | `MapDataVersionPublished` | Never deleted (append-only version lineage); raw snapshots subject to storage-tier lifecycle | Version metadata indefinite; raw snapshots per lifecycle policy |
| `SearchDocument` | **Derived** | Search | OpenSearch index | = source `Place.id` or `GeographicFeature.id` | Search API only | Rebuilt from `PlaceCreated/Updated/Deleted`, `MapDataVersionPublished` | Deleted/reindexed on source deletion | Rebuildable at any time; no independent retention requirement |
| `TileSet` / `TileVersion` | Canonical (as artifact), **Derived** (in content) | Map Tiles | Object storage (tile artifacts) + PostgreSQL (`tiles` schema, version metadata) | ULID + semantic version | CDN, clients | `TileVersionPublished` | Old versions garbage-collected after rollback window | Current + N previous versions |
| `RouteRequest` / `Route` / `RouteLeg` / `RouteStep` | **Ephemeral** (cacheable), audit-logged | Routing | Redis (hot cache) + PostgreSQL (`routing` schema, audit/analytics sample) | ULID | Navigation (session route), clients, Analytics | `RouteRequested`, `RouteComputed` | Cache TTL expiry; audit sample retained per analytics retention | Cache: minutes; audit sample: per analytics retention policy |
| Routing graph (engine-internal) | **Derived** | Routing (via `geodata-pipeline` build) | Routing-engine-native format on disk/object storage | build version ID | `routing-api`/`routing-engine` only | `MapDataVersionPublished` triggers rebuild | Old graph versions retained for rollback | Current + N previous builds |
| `NavigationSession` | Canonical | Navigation | PostgreSQL (`navigation` schema) + Redis (live state) | ULID | Traffic (contributing context), Analytics | `NavigationStarted`/`Rerouted`/`Ended` | Hard-delete/archive after session end + short window | Active + short post-session window, then archived/purged per privacy policy |
| `NavigationLocationUpdate` | **Ephemeral** | Navigation (session-scoped) | Redis (live) + append-only short-term store | ULID | Navigation only (not exposed externally) | none (internal) | Purged shortly after session end | Minutes to hours (session-bound) |
| `TrafficSnapshot` | **Derived** (aggregate) | Traffic | PostgreSQL/PostGIS (`traffic` schema) + Redis (hot tiles) | (road_segment_id, time_bucket) composite | Routing, Navigation, Map-tile (traffic layer), clients | `TrafficSnapshotUpdated` | Rolling window purge | Short-to-medium rolling window (see `13-...md`) |
| `Incident` | Canonical | Traffic | PostgreSQL/PostGIS (`traffic` schema) | ULID | Routing, Navigation, clients | `IncidentReported`/`Resolved` | Soft-delete on resolution + retention | Resolved incidents retained for a bounded analytics window |
| `LocationEvent` | Canonical (raw), privacy-sensitive | Location Telemetry | Kafka (transient) → short-lived PostgreSQL/object storage buffer | ULID | Navigation (session-scoped read), Traffic (aggregation consumer only) | `LocationTelemetryReceived` | Hard-delete after aggregation/short retention window | Short, explicit (see `17-security-privacy-architecture.md`) — never indefinite |
| `SavedPlace` / `PlaceList` | Canonical | Saved Places | PostgreSQL (`places` schema, user-owned partition) | ULID | clients | `SavedPlaceCreated`/`Removed` | Hard-delete on user removal or account deletion | Account lifetime |
| `Contribution` | Canonical | Contributions | PostgreSQL (`places` schema) | ULID | Moderation, Places (on approval) | `ContributionSubmitted`/`Approved`/`Rejected` | Soft-delete (audit retained) | Indefinite (audit) |
| `Review` / `Rating` | Canonical | Reviews & Ratings | PostgreSQL (`places` schema) | ULID | Places (aggregate score), Moderation, Search (signal input) | `ReviewCreated`/`Updated`/`Deleted`/`Moderated` | Soft-delete (moderation-visible tombstone) | Indefinite (tombstoned) |
| `MediaAsset` / `MediaDerivative` | Canonical | Media | PostgreSQL (`media` schema, metadata) + Object storage (binary) | ULID | Places, Reviews, Contributions (by reference) | `MediaUploaded`/`Processed`/`Removed` | Hard-delete of binary on removal; metadata tombstoned | Per media retention policy |
| `Notification` / `NotificationPreference` / `NotificationDeliveryAttempt` | Canonical | Notifications | PostgreSQL (`notifications` schema) | ULID | clients (own notifications only) | `NotificationDelivered`/`Failed` | Hard-delete after retention window | Bounded window (e.g., 90 days), preferences persist with account |
| `Report` / `ModerationCase` / `AdminAction` / `AuditRecord` | Canonical | Moderation & Administration | PostgreSQL (`moderation` schema, append-only for `AuditRecord`) | ULID | all domains (as subjects of moderation/admin actions) | `ReportSubmitted`, `ModerationDecisionMade`, `AdminActionPerformed` | `AuditRecord` never deleted; `Report`/`ModerationCase` soft-delete only | `AuditRecord`: indefinite/compliance-driven; others: indefinite (tombstoned) |

## Rules enforced by this matrix

1. Every row has exactly one canonical owner. No entity appears as canonical in two domains.
2. Any domain consuming another domain's canonical entity does so via API call or the entity's published events — never a direct foreign-schema query.
3. `Derived` and `Ephemeral` rows must be fully reconstructable from their listed canonical sources; loss of a derived/ephemeral store is an operational incident, not a data-loss incident.
4. Privacy-sensitive rows (`LocationEvent`, `NavigationLocationUpdate`, `NavigationSession`) carry explicit retention bounds; no row of this class may default to "indefinite" (cross-reference `17-security-privacy-architecture.md`).
