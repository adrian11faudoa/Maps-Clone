# 26 — Cross-Part Implementation Matrix (Detailed)

This extends `21-cross-part-integration-matrix.md` (Volume 1's boundary-level matrix) to the implementation-grade contracts this volume adds. Read both — 21 tells you which document governs a boundary; this tells you which concrete artifact and field-level contract each implementer touches.

## How this matrix differs from Volume 1's

Volume 1's `21-cross-part-integration-matrix.md` answers "which document governs this boundary." This matrix answers "which concrete file, at what field level, and with what test obligation." An implementation prompt should read the Volume 1 row for orientation, then this row for the actual artifact to conform to and the test category QA will hold it to.
